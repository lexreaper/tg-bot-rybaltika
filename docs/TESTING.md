# Проверки

## Выполнено в среде разработки

- **10 тестов pytest пройдено.** Настоящие FastAPI-запросы через TestClient,
  SQLAlchemy и временная SQLite: полный путь категории → блюда → карточка,
  неизвестные и неправильные id, скрытые блюда, пустая категория, nullable фото,
  отказ базы с безопасной ошибкой 503, повторное заполнение демобазы, раздача UI.
- **19 браузерных проверок Playwright пройдено.** Настоящий Chromium и локальный
  FastAPI: навигация, поиск, состав, цены, загрузка фото, возврат с сохранением
  поиска, отсутствие фото, 404, 503 и повтор, пустое меню/категория, неверный JSON,
  битая картинка, экранирование HTML из API, таймаут, быстрые переходы, отсутствие
  горизонтальной прокрутки на 320/390/1280 px, отсутствие необработанных JS-ошибок.
- Telegram ready/expand, тёмная тема и BackButton проверены **с имитацией SDK**.
- Все три мобильных экрана визуально просмотрены в Chromium.

Тесты не заменяют проверку на реальных клиентах Telegram.
В этой среде не запускались PostgreSQL, Docker Compose, S3 и реальный Telegram-бот.
Рабочий домен, токен и реальные данные ресторана не предоставлены.

## Повторить серверные тесты

В активированном Python-окружении:

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

На Windows вместо `python` можно использовать `.\.venv\Scripts\python.exe`.
Тесты создают отдельную временную SQLite, рабочую базу не меняют.

## Повторить браузерные тесты

В первом терминале: `python run_demo.py`.
В другом терминале в той же папке (нужен Node.js 20+):

```bash
npm install
npx playwright install chromium
npm run test:browser
```

Node.js нужен только для автотестов, не для приложения.
Проверки рассчитаны на исходные демоданные. Если менял demo.db, сначала останови
демосервер и сбрось только этот демонстрационный файл, затем запусти снова.
`TEST_BASE_URL` позволяет указать другой адрес сервера.

## Совместная приёмка команды

| Действие | Ожидаемый результат |
|---|---|
| Открыть меню в Telegram iOS и Android | Интерфейс внутри Mini App, нет наложения на системные элементы |
| Выбрать категорию | GET /menu?category_id=…; только её доступные блюда |
| Открыть блюдо | GET /menu/dishes/…; правильные фото, состав, цена |
| Нажать системную кнопку назад | Карточка → её категория → все категории |
| Сменить светлую/тёмную тему | Читаемые тексты, фон и элементы обновились |
| Быстро сменить категорию | Поздний старый ответ не подменяет новый экран |
| Отключить интернет, перейти к другому экрану | Понятная ошибка; после восстановления повтор работает |
| Открыть пустой раздел / недоступное блюдо | Пустое состояние / 404 |
| Указать недоступную ссылку фото | Заглушка, без сломанной картинки |
| Проверить на PostgreSQL с реальными данными | JSON соответствует docs/API.md, данные совпадают с БД |

## Как показать ошибку вручную

В браузере открой DevTools → Network → Offline, затем выбери другую категорию.
Дождись ошибки, верни Online и нажми «Попробовать снова».
Для проверки 404 открой `http://127.0.0.1:8000/#/dish/99999`.
