# Изменения второго спринта

Первые четыре задачи Кузнецова Семёна выполнены поверх присланного состояния.

- Добавлена навигация Меню / Афиша / Вакансии / Лояльность.
- Добавлены три API-страницы и их пустые/ошибочные состояния.
- Подготовлены макеты публичных и административных экранов.
- Реализован узкий редактор информационной лояльности с ключом доступа,
  сохранением, публикацией/скрытием и проверкой версии при обновлении.
- Добавлены серверные GET API и хранение контента, чтобы frontend работал сразу.
- Новая Alembic-миграция добавляет таблицы, исходные таблицы и меню не удаляются.
- Деморежим дополняет старую SQLite-базу; обновлённый текст не перезаписывается.
- Добавлены тесты нового функционала и инструкция передачи команде.

Административный CRUD мероприятий и вакансий не реализован: для него подготовлены
макеты по задаче 1. Задачи 5–8 не объявляются полностью завершёнными.

# Что добавлено к исходному архиву

- Три адаптивных экрана и статические HTML-макеты.
- REST-клиент, маршрутизация по hash, поиск и возврат с сохранением фильтра/прокрутки.
- Telegram SDK: ready, expand, BackButton, тема, safe area.
- Состояния загрузки/ошибки/пустого списка, retry, отмена устаревших запросов,
  таймаут, валидация ответа, экранирование API-текста, fallback изображений.
- GET /menu/categories с количеством доступных блюд и обложкой.
- 404 для несуществующей категории; обработчик SQLAlchemy ошибок с ответом 503.
- Раздача frontend из FastAPI, необязательный CORS для разделённых серверов.
- Опциональная SQLite-демонстрация; PostgreSQL остаётся основным режимом.
- Docker Compose ожидает готовность PostgreSQL перед стартом приложения.
- .env.example, README, контракт API, описание UI/UX, сценарии приёмки и тесты.

Исходные таблицы, миграция, CRUD, S3 и POST-маршруты сохранены.
Состав взят из существующего description: отдельная миграция не нужна.
Архив для передачи не включает .git, .env, demo.db и установленные зависимости.
Если работаешь в исходном git-репозитории, перенеси файлы этого архива в его корень,
сохрани свой .env и проверь git diff перед коммитом.
